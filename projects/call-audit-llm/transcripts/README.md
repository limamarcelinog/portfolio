# Transcripts

**All eight transcripts here are synthetic.** I wrote them for this project. No
real call was recorded, transcribed or used, and no company, person or deal in
them exists. They are deliberately uneven in quality so the rubric has something
to discriminate between — a set of uniformly good calls proves nothing about a
scoring system.

The scenario is constant: a mid-market retailer evaluating warehouse inventory
software. Holding the domain fixed isolates rep behaviour as the thing that
varies, which is the only way a per-rep comparison means anything.
